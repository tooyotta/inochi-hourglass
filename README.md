# 命の砂時計

限りある時間を大切にするための、静かなWebタイマー。HTML/CSS/JavaScriptのみ。ビルド不要。

## 実行

`python3 -m http.server 8765` をこのディレクトリで実行。

## 仕様

- 初期設定990分。カップ麺3分・ひと休み5分・読書15分・集中25分、任意の1〜990分
- 開始、一時停止、再開、リセット、終了音、任意の目的
- 時刻から残り時間を計算し、スリープ・タブ復帰時に追従
- 黒背景、真鍮・ガラス・粒状の砂をSVGで描画。
- 設定の正本は端末のlocalStorage。計測中の状態はメモリのみ（再読込でリセット）
- 入力データを外部送信しない。Google Fontsへのフォント取得はあり
- reduced-motion、キーボード操作、スマホ画面に対応
- 背景の理念に共感する立場。会見・人物を揶揄しない。非公式

## 成功指標・検証

10秒以内に開始できるUI、残り時間と砂の連動、復帰時の残り時間、一時停止中の停止、入力範囲の検証。
