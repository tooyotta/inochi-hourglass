# 命の砂時計

黒い空間に砂時計を置き、限りある時間を大切にするWebタイマー。HTML/CSS/JavaScript。ビルド不要。

## デザイン

- 写実的な空の砂時計画像を本体として使用。SVGの砂・粒感・流れを重ね、画像の反射を上に合成
- 説明コピー、装飾ケース、操作盤を廃止。砂時計、残り時間、開始ボタンを中心にする
- PCは砂時計と操作の2列。スマホは砂時計の下に操作
- 元素材: `assets/hourglass-body.png`。組み込みimagegenで生成。プロンプトは `design/asset-prompt.md`

## 機能・正本

初期990分。カップ麺3分・休憩5分・読書15分・集中25分、任意1〜990分。開始・一時停止・再開・リセット、目的、終了音。
設定は端末のlocalStorageが正本。計測はメモリ内で、再読み込みでリセット。経過は時刻から計算してスリープ復帰時も追従。
入力データを送信しない。Google Fontsの取得あり。コンセプトに共感する非公式の個人制作。

## 実行と検証

`python3 -m http.server 8791`。開始・停止・再開・終了・入力範囲のロジック検証、公開ページでPC・スマホ表示を確認。
成功条件: 砂時計本体の質感を損なわず砂量と残り時間が連動し、すぐ開始できる。

## 境界と未実装

依頼に基づき専用repositoryのみをGitHub Pagesで公開。画面を閉じた状態での通知、同期、履歴、寿命推定は未実装。音は端末・ブラウザに制限される。
